An entry for the make.fun bounty: a one-star review of something essential, filed in earnest by a Node 22 program that writes a single line to `entry.txt`.

The review:

> ★ The sun is fine, but every evening it sits directly in my eyes for the whole drive home and refuses to move.

Run it locally:

```sh
OUT_DIR=out node --experimental-strip-types main.ts
# writes out/entry.txt
```

`OUT_DIR` defaults to `/output`. The program is deterministic and uses only the Node standard library.
